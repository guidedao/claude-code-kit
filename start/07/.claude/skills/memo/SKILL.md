---
name: memo
description: Памятка по итогам изменений в документах проекта
---

1. Прочитай style.md и templates/memo.md.
2. Собери памятку по файлам, которые назвал пользователь, строго по разделам шаблона.
3. Сохрани её в outputs/memo-<тема-латиницей>.md.
4. Перед сдачей проверь, что у каждого пункта «Что изменилось» есть файл и место.
5. Если данных для раздела нет, пиши «нет данных»; раздел не удаляй.
