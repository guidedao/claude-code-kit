# launch-kit — пульт запуска лендинга

## Карта папки
- inputs/ — исходные материалы: только читать, не менять.
- work/ — черновики и промежуточные файлы.
- outputs/ — готовые результаты.
- archive/ — старые версии: не открывать без просьбы.

## Стиль
- По-русски, коротко, без канцелярита. Даты в формате «12 мая».
- Правила стиля — в style.md, читай перед любым текстом.

## Запреты
- Не придумывать цифры, сроки и статусы.
- Можно только git push в закрытый репозиторий этого проекта; письма, сообщения и публикации — нет.

## Проверки
- У каждого вывода указан источник: файл и строка.
- Если данных не хватает, остановиться и спросить.

## Графики
- Столбцы — ось от нуля; не больше одной шкалы на графике; период из method.md; размер — длиной, не площадью.

## Ветки
- Каждую задачу начинай в новой ветке от main с коротким именем по задаче.
- В main не коммить без моей прямой просьбы.
- Перед переключением ветки рабочая папка должна быть чистой.
- Pull request: остановиться, если нет gh, текущая ветка — main или тесты красные. Слияние решает человек.
