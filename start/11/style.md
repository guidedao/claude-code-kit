# Стиль launch-kit

## Вид страниц

Фон #ffffff, текст #1a1a1a, второстепенный текст #6b6b6b, линии #e5e5e5.
Один акцент — #b42318: только вывод «Запуск под риском»
и пометки «блокер» и «просрочено». «Запуск по плану» — цветом текста,
без зелёного. Шрифт — системный без засечек, числа — системный
моноширинный. Даты — «19 мая», без переноса.
Размеры: вывод 32 px, заголовки блоков 20 px, текст 16 px, пометки 14 px.
Колонка 760 px по центру, поля по бокам 24 px.
Задачи — строками таблицы без рамок: задача, ответственный, срок,
пометка; колонки во всех блоках одной ширины, между строками линия 1 px.
Уже 600 px — список: задача, под ней серым ответственный, срок и пометка.
Чего нет: карточек, теней, скруглений, цветных плашек и пилюль,
градиентов, иконок, эмодзи и заглавных подписей.

## Тексты

- Обращение — на «вы».
- Даты — в формате «12 мая», без «12.05».
- Одно написание терминов во всех текстах: «лендинг», не «лэндинг» и не «landing».
- Без восклицательных знаков.
- Суммы — с пробелом между разрядами: 34 700 ₽.
