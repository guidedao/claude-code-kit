# План сверки выгрузок CRM

Вход: inputs/crm-leads-sept.csv (сентябрь, CSV из CRM) и inputs/crm-leads-oct.xlsx
(октябрь, книга из Google Sheets). Словарь полей — inputs/crm-dictionary.md.
Выход: outputs/reconcile.xlsx с листами «Сентябрь», «Октябрь», «Расхождения», «Сводка».

## Правила
1. Ключ — lead_id.
2. Повторы lead_id в октябре — точные копии: в сверку идут один раз,
   повтор отчитывается как дубликат.
3. Статус — без пробелов по краям и в нижнем регистре.
4. Сумма «4900,00» — число 4900.
5. Дата ДД.ММ.ГГГГ — та же дата.
6. Скрытая строка — обычный лид.
7. Сравниваем только status.

## Инварианты
- строк в сентябре = совпали + пропали;
- уникальных в октябре = совпали + новые;
- строк в октябрьском файле = уникальные + дубликаты.
