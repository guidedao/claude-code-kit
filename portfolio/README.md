# portfolio

Модуль «Сайты: портфолио, питч, лендинг», практика «Сайт-портфолио» и задачи уроков модуля.

## Что внутри

- `heroes/` — материалы трёх вымышленных героев. У каждого `brief.md` (кто он, 6–7 работ с текстом кейса: задача,
  что сделано, результат, роль; о себе, контакты, ограничения) и `images/` с картинками-заглушками:
  - `designer/` — продуктовый дизайнер, 6 работ;
  - `photographer/` — фотограф, 7 работ;
  - `smm/` — SMM-специалист, 6 работ.
  Картинки в `images/` — исходники в том виде, в каком их отдал бы герой: размеры и форматы разные, есть
  тяжёлые файлы. На сайт их кладут после подготовки.
- `site-costs.csv` — первые два года сайта в четырёх вариантах: конструктор с оплатой помесячно и за год,
  WordPress на хостинге, домен с бесплатным хостингом. Колонка `billing`: `month` — цена за месяц, `year` — за
  год, `once` — разовый платёж. `first_year_rub` — цена в первый год, `renewal_rub` — со второго года: домен
  регистратор продаёт по акции только на первый год, тему WordPress покупают один раз.
- `workflow/portfolio-check.yml` — воркфлоу GitHub Actions «Portfolio checks»: на каждый pull request джоб
  `check` клонирует этот набор и запускает проверку сайта.
- `checks/check_portfolio.py` — автопроверка сайта.

Цены в `site-costs.csv` иллюстративные: таблица учит считать, а не выбирать тариф. Перед решением сверьте
текущие цены у конструктора, хостинга и регистратора доменов.

Герои, работы, клиенты и цифры придуманы для курса. Адреса вида `example.com` — заглушки.

## Что копировать

Сайт живёт в отдельном публичном репозитории рядом с `launch-kit`, например `portfolio`. Из набора в
него копируют только воркфлоу:

```bash
mkdir -p .github/workflows
cp ../claude-code-kit/portfolio/workflow/portfolio-check.yml .github/workflows/
```

Материалы героя Claude читает прямо из `../claude-code-kit/portfolio/heroes/<герой>/`, а в репозиторий сайта
кладёт уже подготовленные картинки. Исходники в репозиторий не копируйте: GitHub Pages публикует всё, что в нём
лежит.

## Проверка

Из корня репозитория сайта:

```bash
python3 ../claude-code-kit/portfolio/checks/check_portfolio.py
```

Сайт ищется в корне репозитория, затем в `docs/`; другую папку можно указать: `--site public`. Тринадцать
критериев: страницы кейсов; `title`, description, `og:title`, `og:image`; `alt`; вес картинок до 500 КБ; форматы
JPEG, WebP, AVIF (векторные — SVG); нет «YOUR NAME», «Lorem ipsum», «TODO»; внутренние ссылки; `rel="noopener"`
у внешних ссылок в новой вкладке; телефон шириной 375 px; автозапуск медиа без звука; `prefers-reduced-motion`
для анимаций; текст в HTML; воркфлоу проверки на pull request.

Проверка только читает файлы: ничего не меняет и не ходит в сеть. В CI её запускает воркфлоу из
`workflow/portfolio-check.yml`.
